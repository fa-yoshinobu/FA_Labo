用途から選ぶ PLCツール

まず「既存のアプリで確認したい」のか「自分のプログラムに通信機能を組み込みたい」のかを決めると、必要なツールを絞れます。ライブラリは、PLCの通信方式とプログラムを動かす環境の両方に合わせて選びます。

目的に応じたツール・実装の選び方
やりたいこと候補使い方の例
WindowsでPLCの値を確認するPLC Scopeデバイス範囲を監視し、接続設定と読み出した値を確認する。
データ収集スクリプトを作るPythonライブラリPLCから読み出した値を、自作スクリプトで時刻とともにCSVへ保存する。
Windowsアプリに通信を組み込む.NETライブラリC#で作成する監視画面や常駐サービスからPLCに接続する。
既存のフローにPLCデータを追加するNode-REDノード読み出しノードを既存の表示・記録フローにつなぐ。
組み込み機器や常駐処理で使うC++・Rustライブラリ対応するボードやOS、通信方式を確認してファームウェアや常駐プログラムに組み込む。
Factory I/Oと実機PLCを連携するSLMP / Host Link GatewayFactory I/OのModbus TCP/IP ClientとPLCの間をWindowsゲートウェイで中継する。

通信方式は、三菱MELSECのEthernet通信ならSLMP、KEYENCE KVならHost Link、JTEKT TOYOPUCならComputerLinkが候補です。MELSECのシリアル通信にはMCプロトコル用のC++実装があります。対応機種・通信設定・言語ごとの対応範囲は、それぞれのドキュメントで確認してください。

言語と通信方式の比較を見る（英語）

PLC通信ライブラリの導入手順

  1. PLCと接続方式を確認する。 CPU・通信ユニットの型式、使用するプロトコル、Ethernetまたはシリアルの接続条件を確認します。
  2. 実行環境に合う実装を選ぶ。 使用する言語の対応プロトコルを確認し、パッケージ一覧（英語）から導入先と手順を開きます。
  3. PLC側とクライアント側の設定を合わせる。 EthernetではIPアドレス・ポート・TCP/UDPなど、シリアルでは通信速度などを、選択したプロトコルの手順に沿って設定します。
  4. 少数のデバイスを読み出して確認する。 各実装のGetting startedにある例を使い、対象機種で有効なデバイスの値を確認してから、自分の収集・表示処理へ組み込みます。

使用例：接続確認からデータ収集へ

Windows PCからPLCの値を記録する場合は、最初にPLC Scopeで接続先とデバイスの値を確認します。次に、同じ通信方式に対応するPythonライブラリのサンプルで読み出しを確認し、時刻と値をCSVへ保存する処理を追加します。収集間隔やデバイス数は実際の応答時間を測りながら調整します。

PLC Scopeは接続確認に使うアプリ、Pythonライブラリは収集処理を作るための部品です。アプリケーションの紹介（英語）と、下記の各リポジトリから用途に合うものを選べます。
